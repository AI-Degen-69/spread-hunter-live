### Imports

Absolute, rooted at the repo. `pytest.ini` sets `pythonpath = .`.

```python
from core_brain.order_registry import OrderRegistry, DEFAULT_DB_PATH
from core_brain.quotes import Inventory, QuoteIntent
```

Do not use relative imports (0 in the codebase) or wildcard imports (0 in the codebase).

Modules open with `from __future__ import annotations` (19 of 20 in `core_brain/`).

### Error Handling

Raise domain-specific exceptions that name the refusal; do not swallow errors.

```python
class PairCompletionRefused(RuntimeError):
    ...

if size < MIN_ORDER_SHARES:
    raise PairCompletionRefused(
        f"Completable size {size:.4f} is below the venue minimum of "
        f"{MIN_ORDER_SHARES}."
    )
```

Narrow `except` clauses only (`except sqlite3.Error`, `except OSError`). A bare
`except Exception: pass` in an execution path hides money-losing state.

## Testing

- Framework: **pytest**. File pattern: **`test_*.py`** in `tests/`.
- `tests/conftest.py` is hermetic: it scrubs credentials from `os.environ` and
  blocks every non-loopback socket. Opt out per-test with
  `@pytest.mark.allow_network`.
- Platform-specific tests carry `@pytest.mark.skipif(sys.platform ...)`.
- CI runs the suite on ubuntu + windows via `.github/workflows/tests.yml`.

```bash
python -m pytest -q
```

## Commits

Conventional commits. Prefixes seen: `feat`, `fix`, `docs`. Imperative mood,
concise first line.

```text
fix(core_brain): size pair completion against the asks ladder
```

## Trading-Engine Guardrails

This repository moves real money. Beyond style:

- **Sizing changes need a test.** `complete_pair` sizes against `ask_depth`
  (asks ladder) — `depth_at_or_above` reads *bids* and will oversize a buy.
- **Never close a connection inside `with get_connection(...)`.** The context
  manager commits on exit; use `contextlib.closing`.
- **Fill attribution must not silently drop fills.** Under-counting a position
  invites fresh exposure on top of it.
- **Bot-authored PRs are not reviewed code.** See `CONTRIBUTING` guidance and
  the CI gate before merging any automated fix bundle.
